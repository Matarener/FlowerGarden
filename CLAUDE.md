# CLAUDE.md

Игра «Цветочная поляна» для Telegram Mini App: ферма на время. Ёжик Тиша сажает цветы, поливает, собирает и продаёт покупателям у прилавка; цель уровня — набрать монеты за отведённое время.
Чистый JavaScript (ES-модули), движок на Canvas 2D, скелетная анимация и синтез звука — общие с игрой «Грибница» (MusroomFight), скопированы оттуда.
Внешних библиотек в игре нет; esbuild нужен только для сборки в один файл.

Общение с владельцем проекта — на русском. Комментарии в коде и тексты интерфейса — тоже на русском.

## Команды

- `node tools/serve.mjs` — сервер для разработки, http://localhost:5173.
- `npm install` — один раз, ставит esbuild.
- `npm run build` — сборка в `dist/index.html` (вся игра одним файлом).
- `node tools/sim.mjs` — проверка баланса: бот проходит все 30 уровней на модели без графики. После правок чисел в `data/content.js` прогонять.
- Публикация: push в `main` → GitHub Actions (`.github/workflows/pages.yml`) собирает и выкладывает на GitHub Pages.

Проверка руками: титульный экран → карта → уровень 1 (посадить, полить дважды, собрать, отдать покупателю) → победа → лавка. В консоли браузера доступен `flowerglade` (app): `flowerglade.router.go('level', 12)`, `flowerglade.engine.scene.model`.

## Архитектура

Зависимости в одну сторону: `src/game` → `src/skeleton` → `src/engine`. Движок и скелет не знают об игре.

- `src/engine/`, `src/skeleton/` — копия из Грибницы. Исправления движка стоит переносить в обе игры.
- `src/game/data/content.js` — цветы, правила, 30 уровней (`levelDef`), цели, улучшения. `skeleton.js` — скелет зверька и все анимации.
- `src/game/level/LevelModel.js` — вся логика уровня без графики: грядки, лейка, корзинка, покупатели, жуки, очередь дел Тиши (до 5). `layout.js` — где что стоит.
- `src/game/state.js` — `GameState`: кошелёк, звёзды, улучшения; `toSave()` / `restore()`, `SAVE_VERSION`.
- `src/game/save.js` — localStorage + Telegram CloudStorage.
- `src/game/art/` — рисование кодом: `critters.js` (Тиша и покупатели), `flowers.js`, `gardenArt.js` (поляна под ширину экрана, грядки, колодец, прилавок…).
- `src/game/scenes/` — `TitleScene`, `LevelScene` (+ `level/PlantView`, `level/CustomerView`).
- `src/game/ui/` — HTML поверх холста: карта уровней, интерфейс уровня, лавка, настройки.
- `src/game/router.js` — экраны (title, map, level), музыка, пауза цикла.

## Правила производительности

Те же, что в Грибнице: всё неподвижное — `setStatic()`, в кадре только `drawImage` запечённых текстур, текст через `Label`, ничего не создавать во время анимаций (пулы), звук рендерится заранее, цикл на паузе, когда игру не видно.

## Стиль

Мультяшная графика кодом: толстый контур `0x3e2512`, мягкие тени, блики. Размеры интерфейса — `calc(var(--u) * N)`. Свои герои и графика: механики похожи на казуальные фермы, но это не копия какой-то конкретной игры.
