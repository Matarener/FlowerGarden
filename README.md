# Цветочная поляна

Казуальная ферма на время для Telegram Mini App. Помоги ёжику Тише вырастить цветы и продать их лесным покупателям.

## Как играть

- Выбери семена внизу и нажми на пустую грядку — Тиша посадит цветок.
- Росток просит воды дважды (капля над грядкой). Нажми на грядку, чтобы полить. Вода в лейке кончается — нажми на колодец.
- Распустившийся цветок нажатием собирается в корзинку. Не тяни: через время он завянет.
- Нажми на покупателя — Тиша отдаст то, что лежит в корзинке и есть в заказе. Чем быстрее, тем больше чаевые.
- С 4-го уровня прилетают жуки: нажми на жука, чтобы прогнать его, за это дают монетку.
- С 6-го уровня на столике из трёх одинаковых цветов вяжется букет, он стоит как четыре.
- Тиша запоминает до пяти дел подряд — номера видны над целями.

Цель уровня — набрать монеты за отведённое время. Звёзды — за скорость. Монеты за уровни тратятся в лавке: лейка, корзинка, сапожки, тёплая земля, колокольчик, пугало.

30 уровней на трёх полянах: у дома, у ручья и на холме. Новые цветы: ромашка, тюльпан, василёк, роза, подсолнух.

## Запуск

```
npm install
node tools/serve.mjs     # http://localhost:5173
npm run build            # dist/index.html — вся игра одним файлом
node tools/sim.mjs       # проверка баланса ботом
```

Движок, скелетная анимация и синтез звука — общие с игрой «Грибница».
